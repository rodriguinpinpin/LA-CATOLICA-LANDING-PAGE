# SectionTitle

Título de sección en dos líneas: una línea pequeña (`kicker`) y una línea fuerte (`h2`) en Bitter, color `navy-800`.

Patrón del brochure: una barra horizontal `navy-800` sale del borde izquierdo de la página hasta el título (“▬ Plan Curricular”, “Servicios de / Apoyo al Aprendizaje”). Opcionalmente una línea fina `blue-500` debajo. Usar una vez por sección; no apilar dos títulos. Alinear a la izquierda; centrado solo en bloques simétricos (Principios Educativos, Valores).

Clases: `.lc-title`, `.bar`, `.kicker`, `h2`, `.rule`.
