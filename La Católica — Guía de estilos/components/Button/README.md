# Button

Botones de acción de la landing; el principal es amarillo institucional con texto azul.

- **primary** (`gold-500` + texto `navy-900`): una sola vez por vista, para la acción de conversión (“Solicitar vacante”, “Agenda tu visita”). Funciona sobre blanco y sobre navy.
- **secondary** (`navy-800` + blanco): acciones de apoyo (“Ver plan curricular”).
- **outline**: terciaria sobre fondos claros. **ghost-dark**: terciaria sobre el hero navy.
- **whatsapp** (`accent-green-text`): contacto directo al 994 384 050.

Texto en tipo `button` (Poppins 600, 16px), verbo primero y en oración (no TODO MAYÚSCULAS). Alto mínimo 48px en móvil. Foco: anillo `focus-ring` de 2px + halo navy.

Clases: `.lc-btn` + `.lc-btn-primary | -secondary | -outline | -ghost-dark | -whatsapp`.
