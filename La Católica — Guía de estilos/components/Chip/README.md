# Chip

Píldoras para niveles (Kinder, Primaria, Secundaria), fechas destacadas y filtros, y la pestaña grande `.lc-tab` (celeste `sky-500`, texto Bitter `navy-900`) para encabezar bloques como “Calendarización”.

Variantes: por defecto (`surface-soft`), `.navy`, `.gold`. Un chip activo usa `.navy`.
