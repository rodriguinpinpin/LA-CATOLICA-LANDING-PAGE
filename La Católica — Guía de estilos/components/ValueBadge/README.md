# ValueBadge

Insignia de valor institucional: círculo `gold-500` con ícono navy y etiqueta en píldora con borde dorado que se superpone al círculo.

Los cinco valores del colegio: **Curiosidad, Autonomía, Colaboración, Respeto, Responsabilidad**. Mostrar los cinco juntos (3 + 2 en el brochure; fila de 5 en escritorio, grilla 2-col en móvil). Etiqueta en Poppins 700, 13px, `navy-800` — nunca texto amarillo sobre blanco.

Clases: `.lc-value`, `.circle`, `.label`.
